Procurement Writing Engine composes local writing providers for English and Persian procurement prose, with explicit source ranges and review-only results. No LLM required by the default profile.

Source repository · Releases

Built for procurement software

Harper for English, restricted Virastar for Persian orthography, Textlint for writing policies, and optional terminology or local grammar adapters. Applications must supply an authoritative region map and own authorization. Nothing is automatically applied.
