# Changelog

## 0.1.0-alpha.1 — initial public release candidate

- Independent, review-only provider composition for English and Persian procurement prose.
- Adapters for Harper, Virastar, experimental Virastar TS, Textlint, Vale, STE100 and LanguageTool.
- Host-owned complete regions, UTF-16/grapheme validation, bounded execution and advisory provenance.
- Synthetic regression corpus and dependency-free contract suite; real upstream and browser acceptance gates.
- Local worker-based demonstration, package metadata, documentation, release automation and brand assets.

The initial release is an **alpha**, not certified technical English, a production integration or a full multilingual grammar checker. Optional external engines and real host authorization remain separately qualified.
