# Procurement Writing Engine 0.1.0-alpha.8

Conservative offline English/Persian procurement writing review prerelease. Publication is conditional on the exact commit passing all seven technical CI jobs and explicit maintainer release dispatch.

## Included

- Managed local review profile, optional host-owned Lilak dictionary preparation and validation, source-only abstention and bounded context/frequency ranking API.
- Explicit protected regions, conservative demo routing, exact UTF-16 source anchors and opt-in adaptive preference ranking.
- Bilingual regression checks and clean consumer package verification. No new mandatory runtime dependency; no automatic application.

## Measured limitations

FAspell development comparison (3,633 eligible human word pairs): base PWE top-1 1,532, top-4 2,345; 55 gold target words received suggestions. These are isolated lexical metrics, not overall writing accuracy. OCR and general grammar coverage remain limited. Source and evaluation exclusions are documented in PERSIAN_QUALIFICATION_DECISION.md. Full ManaTTS projection succeeded but evidence validation failed; the experiment is deferred. No frequency corpus, nspell cascade, new neural model or research dataset is included in this package. No actual iOS device certification, production or RMS deployment implied. Host must provide authoritative protection and validate permissions, snapshots and edits.
