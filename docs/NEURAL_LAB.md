# Browser neural qualification lab

This opt-in experiment runs a real Transformers.js 4.3.2 pipeline with pinned model revisions. It uses a separate worker and five fixed public fixtures; it never accepts the user's free-text field. The default lightweight review is unchanged. No external network traffic occurs from this lab until the explicit Start action. Third-party runtime and model assets are fetched after consent. This experiment is deliberately NOT a strict offline sandbox or the local-files-only SDK mode; do not enter confidential data. No automatic backend fallback. Cancellation terminates the worker, and the page has a resource time limit. The existing guarded local-generation adapter validates each batch before displaying candidates. Exact fixture matches, misses, unexpected candidates, blocked cases, load and inference times are reported; they are not a statistical quality estimate. Runtime import is pinned to 4.3.2; model revisions are pinned, but asset hash verification, license audit and actual browser inference are still required. Qwen3.5 is experimental; Qwen3 provides a separate comparison. CI tests fixture scoring and the opt-in gate, not actual downloads/inference.

Sources: https://huggingface.co/docs/transformers.js/main/en/installation ; https://huggingface.co/onnx-community/Qwen3.5-0.8B-Text-ONNX ; https://huggingface.co/onnx-community/Qwen3-0.6B-ONNX/blob/b1ece21c06dfce3839272e86b7fa12a985d97a7a/onnx/model_q4.onnx
