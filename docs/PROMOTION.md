## Launch post (publish only after GitHub release exists)

Procurement Writing Engine is an open-source alpha for English and Persian writing review in procurement software. It composes existing language engines instead of requiring a large language model, and keeps host-classified technical ranges outside grammar providers. The library produces review-only, source-anchored findings and ships with a local browser demo, TypeScript declarations, tests and explicit security boundaries.

Repository: https://github.com/FireXCore/procurement-writing-engine

The project is experimental. Contributions with synthetic RFQ, quotation and technical-writing examples are welcome. No claims of certified compliance or production readiness.
