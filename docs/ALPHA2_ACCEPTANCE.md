# Alpha.2 acceptance matrix

These are synthetic regression cases derived from public demo feedback, not a statistically representative grammar benchmark.

- English: spelling and procurement alternative ranking, two selected agreement forms, repetition, quotation deadline, clean prose.
- Persian: Arabic glyph normalization, half-space, clean prose.
- Mixed industrial content: known Rosemount sample, explicit part number and Persian quantity are protected while surrounding eligible prose is reviewed.
- Unknown technical or mixed-script gaps remain unreviewed, with explicit partial-result diagnostics.
- Browser: automatic language routing regardless of sample button, input immutability, cancellation, stale-result invalidation, and no external requests.

The demo classifier is restricted to synthetic patterns. It is not an authoritative Region Map generator for production. The SDK remains review-only and requires host-provided regions. The agreement policy has narrow patterns and does not claim general English grammar coverage. Upstream quality and optional service acceptance remain separate. See current GitHub CI for executed results; no npm publication is authorized at this stage.
