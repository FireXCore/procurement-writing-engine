# موتور نگارش Procurement

کتابخانه مستقل و متن‌باز برای بررسی نگارش تجاری و فنی انگلیسی و فارسی، با ترکیب موتورهای آماده و بدون نیاز به مدل زبانی بزرگ در پروفایل پیش‌فرض. نسخه فعلی آلفا است و تأیید تولید ندارد.

- Harper برای املا و گرامر انگلیسی؛ Virastar برای نگارش فارسی.
- Textlint برای سیاست‌های سازمانی و Vale، STE100 و LanguageTool به صورت اختیاری.
- پیشنهادهای قابل بازبینی با موقعیت UTF-16 و کنترل محدوده‌های حفاظت‌شده.
- برنامه میزبان مسئول مجوزها، جداسازی کاربران و تأمین‌کنندگان، و تعیین محدوده معتبر متن است. هیچ پیشنهاد به صورت خودکار اعمال نمی‌شود.

## اجرای آزمایشی

پس از تولید Lockfile واقعی توسط فرایند انتشار، Node.js نسخه 22.12 یا بالاتر و مرورگر Chromium سازگار لازم است.

```sh
npm ci --ignore-scripts
npm run verify
npm run demo
```

فقط با داده مصنوعی آزمایش کنید. وضعیت تست‌های اجراشده و محدودیت‌ها در [گزارش اعتبارسنجی](LOCAL_VERIFICATION.md) و [فرایند انتشار](RELEASE.md) آمده است. [معماری](ARCHITECTURE.md)، [قرارداد API](API.md)، [امنیت](../SECURITY.md) و [مجوز اجزا](../THIRD_PARTY.md) را قبل از استفاده مطالعه کنید.
