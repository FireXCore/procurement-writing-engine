# Integrated preview qualification

Sources rechecked 2026-11-26: NeveshtYar 4.9.2 uses dictionary-fa 2.0.0; its generated lexical priors use normalized Hunspell roots and numeric fingerprints. PWE chooses exact root membership, excludes explicit NEEDAFFIX/ONLYINCOMPOUND/NOSUGGEST flags, preserves original UTF-16 anchors and never treats affix-root extraction as full morphology. TypeAssist MIT source separates third-party linguistic data. WriteRight merger discards overlapping competitors; PWE retains them. SpellChecker uses pluggable deterministic ranking. No external implementation copied.

The optional demo dictionary is built from the exact npm tarball version/integrity found in NeveshtYar's lockfile. Build and upstream integration validate the actual dictionary count and an exact source-anchored correction. The connector could not retrieve the large upstream dictionary file; no claim of prior full inspection is made. The SDK remains host-lexicon based, with no mandatory dictionary dependency. Apache notice is served with the demo. Optional dictionary is not a full morphology engine and may propose changes to unknown Persian names; the host region map remains authoritative.

Preference persistence is explicitly opt-in, one synthetic demo profile per browser origin, exact word pairs only, no document history. After reload the controls are off; re-enable both to restore. Disabling learning or Clear preferences deletes the demo key (storage failure is surfaced). Concurrent tabs are not synchronized; production needs per-user/vendor storage and concurrency policy. No neural model is required. No automatic application.

Release qualification: all five existing CI checks plus real dictionary integration, browser optional dictionary test, persistence/clear test, previous regression tests, network isolation for default paths, and independent Persian/English evaluation. ParsProof (https://huggingface.co/datasets/sbunlp/ParsProof) covers 52 error types; dataset and model licensing and independent benchmark execution are not yet completed. GECToR/Proofbird remains a separate unqualified option. No stable or alpha.8 package is published by this branch.
